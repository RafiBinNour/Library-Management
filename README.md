# BookNest — Library Management Website

HTML, CSS এবং সাধারণ JavaScript দিয়ে তৈরি একটি ছোট লাইব্রেরি ম্যানেজমেন্ট ওয়েবসাইট। কোনো Python, ডাটাবেস সার্ভার, npm বা ইন্টারনেট সংযোগ ছাড়াই কম্পিউটারের আধুনিক ব্রাউজারে এটি ব্যবহার করা যায়।

## দ্রুত চালু করুন

1. ZIP ফাইলটি ডাউনলোড করে **Extract All** করুন।
2. `library_website` ফোল্ডারে `index.html` ফাইলটি ডাবল-ক্লিক করুন।
3. Chrome, Edge বা Firefox-এ ড্যাশবোর্ড খুলবে।

অথবা VS Code-এ ফোল্ডারটি খুলে `index.html`-এ রাইট-ক্লিক করে **Open with Live Server** ব্যবহার করতে পারেন (Live Server এক্সটেনশন থাকলে)।

প্রথমবার খুললে কিছু নমুনা বই, সদস্য ও লোন দেখাবে। প্রয়োজনে সম্পাদনা করুন। যেসব বইয়ের লোন ইতিহাস আছে সেগুলো ইতিহাস রক্ষার জন্য ডিলিট করা যায় না।

## কী কী করা যায়

- **Overview:** বই ও সদস্যের সংখ্যা, চলমান/মেয়াদোত্তীর্ণ লোন, সাম্প্রতিক কার্যকলাপ এবং সংগ্রহের সারসংক্ষেপ।
- **Books:** বই যোগ, সম্পাদনা, অনুসন্ধান, উপলব্ধতা ফিল্টার এবং ইতিহাসবিহীন বই ডিলিট। কপি সংখ্যার হিসাব স্বয়ংক্রিয়।
- **Members:** সদস্য যোগ/সম্পাদনা, অনুসন্ধান, ইতিহাস দেখা এবং সক্রিয়/নিষ্ক্রিয় করা। চলমান লোন থাকলে নিষ্ক্রিয় করা যায় না।
- **Issue books:** সক্রিয় সদস্যকে উপলব্ধ কপি ইস্যু; ইস্যু ও ফেরতের তারিখ নির্ধারণ। একই সদস্য একই বই একসঙ্গে দুবার নিতে পারে না।
- **Return books:** বর্তমান লোন ফেরত দেওয়া; নিশ্চিত করার আগে বিলম্বের দিন ও জরিমানা দেখা। জরিমানা = মেয়াদোত্তীর্ণ দিন × সেটিংসে থাকা বর্তমান দৈনিক হার।
- **Borrowing history:** লোন দেখা, অনুসন্ধান/ফিল্টার এবং CSV ডাউনলোড।
- **Reports & analytics:** ছয় মাসের ঋণের চার্ট, জনপ্রিয় বই/সদস্য ও মেয়াদোত্তীর্ণ লোন; বইয়ের সারসংক্ষেপ CSV ডাউনলোড।
- **Settings:** লাইব্রেরির নাম, ডিফল্ট ইস্যুর মেয়াদ, জরিমানার হার ও JSON ব্যাকআপ/রিস্টোর।

## তথ্য কোথায় থাকে? গুরুত্বপূর্ণ সীমাবদ্ধতা

এই সংস্করণে তথ্য **ব্রাউজারের localStorage-এ** থাকে—SQLite বা কোনো অনলাইন সার্ভারে নয়। এটি আগের Python ডেস্কটপ অ্যাপের ডাটাবেসের সঙ্গে স্বয়ংক্রিয়ভাবে যুক্ত নয়।

- একই ব্রাউজার, একই ডিভাইস ও একই ওয়েব ঠিকানায় আবার খুললে তথ্য সাধারণত থেকে যায়। Live Server, `file://`, অথবা অন্য হোস্ট/পোর্ট আলাদা storage ব্যবহার করতে পারে।
- অন্য ডিভাইস বা ব্রাউজারে তথ্য স্বয়ংক্রিয়ভাবে দেখা যাবে না। প্রাইভেট ব্রাউজিং শেষ করলে বা ব্রাউজারের সাইট ডেটা মুছে দিলে তথ্য হারাতে পারে। ব্রাউজারের নিরাপত্তা সেটিংসের কারণে সরাসরি `file://`-এ storage আচরণ ভিন্ন হতে পারে; দরকার হলে Live Server ব্যবহার করুন।
- **Settings → Download JSON backup** দিয়ে নিয়মিত ব্যাকআপ রাখুন। একই পেজে **Restore backup** বেছে সেটি ফেরত আনা যায়। রিস্টোর করলে বর্তমান তথ্য প্রতিস্থাপিত হবে; কেবল বিশ্বস্ত ব্যাকআপ ব্যবহার করুন।
- এতে লগইন, একাধিক ব্যবহারকারীর সমন্বয় বা সার্ভার-সাইড নিরাপত্তা নেই। তাই ব্যক্তিগত/সংবেদনশীল তথ্য দিয়ে অনলাইনে প্রকাশ বা বাস্তব প্রতিষ্ঠানের বহু-ব্যবহারকারী সিস্টেম হিসেবে ব্যবহার করা উচিত নয়।
- `localStorage` অনুমতি বন্ধ থাকলে বা জায়গা ফুরিয়ে গেলে সংরক্ষণ ব্যর্থ হতে পারে।

## ফাইল পরিচিতি

```text
library_website/
├── index.html   # পেজের কাঠামো ও ডায়ালগ
├── style.css    # রং, লেআউট, কার্ড ও মোবাইল রেসপনসিভ ডিজাইন
├── script.js    # ডেটা, নিয়ম, পেজ দেখানো, ফর্ম, রিপোর্ট ও ব্যাকআপ
└── README.md    # চালানো, ব্যবহার ও সীমাবদ্ধতার নির্দেশনা
```

### শেখার জন্য

- **HTML:** `header`, `nav`, `main`, `dialog` পেজের অংশগুলো তৈরি করে।
- **CSS:** Flexbox ও Grid দিয়ে লেআউট, media query দিয়ে ছোট স্ক্রিনের ডিজাইন তৈরি করা হয়েছে।
- **JavaScript:** অবজেক্ট ও অ্যারে ডেটা ধরে; ফাংশন দিয়ে লোনের হিসাব করা হয়; event listener ক্লিক ও ফর্ম সামলায়; `localStorage` তথ্য সংরক্ষণ করে।

## সমস্যা হলে

- **পেজে শুধু লেখা, ডিজাইন নেই:** ZIP থেকে সম্পূর্ণ ফোল্ডার extract হয়েছে কি না দেখুন; `style.css` ও `script.js` অবশ্যই `index.html`-এর পাশে থাকতে হবে।
- **বাটন কাজ করে না:** ব্রাউজারে JavaScript চালু আছে কি না দেখুন। আধুনিক Chrome, Edge বা Firefox ব্যবহার করুন।
- **তথ্য দেখা যাচ্ছে না:** আগের মতো একই ব্রাউজার ও ঠিকানা ব্যবহার করুন। প্রয়োজনে সংরক্ষিত JSON ব্যাকআপ রিস্টোর করুন।
- **কপি বা সদস্য ডিলিট/নিষ্ক্রিয় হচ্ছে না:** সংশ্লিষ্ট বইয়ের ইতিহাস বা সদস্যের সক্রিয় লোন আছে কি না পরীক্ষা করুন; এটি ইতিহাস ও স্টক রক্ষার নিয়ম।
